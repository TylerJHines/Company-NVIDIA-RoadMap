# Version 15 — NCP-ARI study links

Based on the complete Version 14 academy package. Added two Udemy resources to NCP-ARI > Courses and suggested reading. All four existing NCP-ARI resources remain unchanged. Each new resource gets a completion checkbox through the existing academy logic.

## Deploy

If your GitHub site is already running Version 14, replace only the root `data.js` file. No Firebase configuration, Firestore rules, or other files need changing. If deploying from scratch, upload the full contents of this ZIP and preserve your working Firebase configuration if different.

Note: Existing progress checkboxes are index-based. The new links are appended at the end to preserve existing completion indices. Course availability and coupon pricing are controlled by Udemy.
